# Comunidade Shekinah

Espaço exclusivo para o aplicativo da Comunidade Shekinah.

## Separação

- O código deste aplicativo fica neste diretório.
- A autenticação e os dados da Shekinah devem usar um projeto de banco independente.
- Nenhum cadastro, senha, token ou segredo de produção deve ser gravado neste repositório.
- Não reutilizar tabelas ou credenciais do projeto SEDAM/SEPAT.
